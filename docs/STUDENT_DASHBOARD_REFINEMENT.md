# Student dashboard icon and theme refinement

The approved Learning Insights composition, typography, XP values, assessment counts, navigation destinations, and card geometry are preserved. The compact LMS summary requested separately remains in place.

- The reusable student icon mapping now imports official Phosphor filled SVG components, one icon per import. Home is orange; practice/profile are blue; exams green; progress/report cards purple; notifications/calendar pink; achievements gold, purple, or green. Dark-theme icon colors become brighter without extra decorative tiles. Only the current navigation destination has an interaction-state background.
- Achievements, header actions, notification types, exam tools, and student report icons use the same mapping. No trophy illustration was fabricated from these glyphs.
- With the user's explicit approval to use a newly sourced trophy, the XP illustration alternates between the unchanged existing `/gold-card-wave.svg` and Microsoft Fluent Emoji's licensed trophy every five seconds. The trophy's paths are unchanged; its base fill is adapted to purple. Source, adaptation, and MIT license are stored beside the asset. This is a newly approved sourced asset, not recovery of the missing original trophy.
- Only illustration opacity/transform changes. The slot remains absolute and fixed in size. The CSS crossfade takes 600 ms with 4px movement. There are manual choices and a pause/play control. Hidden tabs clear the interval; reduced motion disables both autoplay and transitions. Event listeners and timers are cleaned up on unmount.
- Theme selection is applied before paint and survives reload/navigation. Native controls receive `color-scheme`; the student provider follows system preference until a choice is saved and synchronizes storage changes. Shared dark theme tokens and button foreground tokens improve text contrast.
- Student exam, assessment preview, results, review dialogs, settings, dashboard notices, notifications, community, and learning-library surfaces use theme-aware colors. Calculator controls and scratchpad tools adapt too; the scratchpad uses valid pen-color values and a transparent canvas. Printed A4 reports retain white paper and dark ink.
- Shared sign-in forms, notification popovers, academic badges/switcher, and report-workspace controls also use theme tokens. A web Guardian theme attribute/class conflict was corrected so selecting light cannot leave the dark CSS class behind. Native Guardian app UI is outside this student refinement.

Sources: [Phosphor React](https://github.com/phosphor-icons/react), [Fluent Emoji trophy](https://github.com/microsoft/fluentui-emoji/blob/main/assets/Trophy/Flat/trophy_flat.svg), [Fluent Emoji MIT license](https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE).

Verification uses the production export and intercepted browser fixtures, never live school data. The refinement checks cover both illustrations, automatic timing, hidden/reduced-motion behavior, stable XP text/geometry, persisted dark mode, student pages, review/practice dialogs, exam tools, final attempt summary, mobile overflow, and all four login forms.
